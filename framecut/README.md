# FRAMECUT — その写真、映画にしよう。

https://010101001100.github.io/sheetclean-lite/framecut/

写真1〜4枚を、10秒前後の映画予告編風動画にする無料・登録不要のブラウザ制作ツール。縦型9:16と横型16:9、5ジャンルの色味・字幕・切替演出、オリジナルのシンプルなサウンド、PNGのポスター保存、MP4/WebM動画の保存とスマホの共有シートに対応。

- サーバーに写真をアップロードしない。画像と動画は端末内で生成。
- 対応ブラウザ・コーデックによって動画形式は異なる。WebMが出る端末もある。動画保存できない場合はPNGの静止画書き出しが可能。
- ロゴは初期表示ONだが編集画面でOFFにできる。画像・動画を加工するAIモデルは使用しない。
- 出力検証: Chromium desktop/mobile、ユーザー写真読込、色変更、縦横変更、PNG 720×1280、MP4映像音声ストリーム。実際のSNS投稿やすべてのiOS端末での互換性は未確認。
- SEO: 日本語タイトル/description、OGメタ、構造化データ、sitemap.xml。サイトへの実アクセス数は未確認で、自然流入を保証しない。
