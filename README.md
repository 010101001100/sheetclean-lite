# SheetClean Lite — 無料CSV整理ツール

登録不要・ファイルの外部送信不要の、ブラウザ完結型CSV整理ツールです。

## 機能

- CSVの完全一致重複行の削除（先頭行は見出しとして維持）
- セル前後の空白削除（任意）
- UTF-8 / Shift_JISの読み込み、UTF-8 BOM付きCSVの書き出し
- 整理後の先頭8行プレビュー
- 表計算ソフトで数式として解釈され得るセルの保護（任意・初期設定ON）
- PC／スマートフォン向け表示

## プライバシーと制限

CSVの内容は利用者のブラウザ内でのみ処理します。外部へのアップロード、広告トラッキング、アカウント登録はありません。ただし、ページ閲覧そのものについてホスティングサービス側でアクセスログを扱うことがあります。

最大8MiB。Excel .xlsx形式は非対応です。CSV出力は文字列の前にアポストロフィが付く場合があり、負の数値も影響を受けます。防御の完全性や元データの完全復元は保証されません。元データのバックアップを推奨します。

現状のまま無料試用できるツールです。有料機能、外部API、認証情報、AI開発工場の内部コードは含みません。
