# NOMA — 好きなものを、ひとつの世界に。

小さなWebサイトを作る、登録不要のビジュアルスタジオ。画像・テキスト・タイトル・URL・チェックリスト・引用をドラッグして自由に配置し、**単体で表示できるHTMLファイル**として持ち出せます。

## 使い方

1. サンプル作品を見ながら、カードを追加する。
2. カード上部のつまみをドラッグして動かす。カードを選んで、文章やサイズを調整する。
3. 画像は「画像を置く」から選ぶか、画像ファイルをドロップ／貼り付けする。
4. **Webページにする** → HTMLを保存。閲覧専用のHTMLはネット接続なしでも開けます。別のホスティングにアップロードすれば公開できます。
5. さらに編集する予定なら **編集用バックアップ（JSON）** を保存。復元は「読み込む」から。

## 実装・制限

- 全てのレイアウト編集と書き出しはブラウザ内で処理され、入力データはサイト運営者のサーバーに送信しません。ただし、静的サイトの配信と、利用者がクリックした外部リンクについては、それぞれ通常のアクセスが発生します。
- IndexedDBに自動保存します。プライベートブラウザなどで保存が制限される場合があります。重要な作品はJSONバックアップを保存してください。
- 書き出したHTMLは**閲覧専用**です。編集を続けるにはNOMAにJSONを読み込んでください。
- 作品は固定1400×940pxキャンバスを各画面に縮小表示します。カードの配置は手動で、複数端末での同時編集・同期はできません。
- 最大70カード。画像はPNG/JPEG/WEBP/GIF、1枚9MBまで。ファイルは必要に応じて画像をWebPに圧縮しますが、GIFは動きを保持するため元のデータを利用します。ブラウザの保存容量上限により保存できない場合があります。
- リンクはhttp/httpsだけを許可。JSONインポートは内容を検証してから表示します。
- GitHub Pagesで公開。ブラウザテストは主要操作のスモークテストであり、あらゆる端末・内容での動作を保証しません。
