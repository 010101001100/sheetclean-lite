# わかる？ — ふたりの解像度バトル

12問の選択肢から、相手の理解度と回答一致率を比べる軽い対戦ゲーム。

## 遊び方

1. 友達・恋人・同居の3テーマから選び、自分の12問の答えを入力する。
2. ブラウザだけで生成した挑戦URLを相手に送る。
3. 相手は「挑戦者の回答予想」と「自分自身の回答」の両方を選ぶ。
4. 「理解度 = 予想の正解数 ÷ 12」と「相性 = 実際の回答の一致数 ÷ 12」を表示する。結果PNGと返送用の結果リンクを生成する。

## プライバシーと正確性

回答は URL の fragment 部分にバージョン付 JSON を UTF-8/Base64url エンコードしたもので、暗号化ではありません。回答や名前を知っている人には見られます。アカウント・サーバーデータベース・第三者分析・広告は未使用。ホスティング時の通常のアクセスログは別です。個人情報・秘密は入力しないでください。

12問の単純一致率に過ぎず、科学的・心理学的な相性や関係性の診断ではありません。リンク共有の都合上、A のブラウザには B の結果は自動的に届きません（B が結果URLを返送する必要があります）。

Vanilla HTML/CSS/JS、外部 JS / フォント無し。GitHub Pages 上で動作。
