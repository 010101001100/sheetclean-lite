# PON! RELAY — みんなでドット絵リレー

会員登録なしの無料ピクセルアートリレー。32×20マスの絵を、1人最大40マスだけ描いて、URLで次の人に渡します。最大12人で共同の1枚ができあがります。

## 主な機能

- スマホ・マウス・キーボードでペイント、消しゴム、取り消し
- 以前の参加者の塗りは変更できません
- 作品・お題・参加者名をURLのクエリ文字列で受け渡し、描いた後は新しいURLが生成されます
- LINEシェア、一般共有、招待リンクコピー、PNG保存
- 日本時間に基づく日替わりのお題・自由なお題・試遊サンプル
- 編集途中の復元（localStorage を使えるブラウザのみ）

## 仕様と注意

サーバー、データベース、本人確認、共有ランキング、リアルタイム同期はありません。古いリンクの絵は更新されず、描き進めるたびに新しいリンクを次の人へ送ってください。共有URLには作品・名前・お題が入ります。個人情報や秘密情報は入力しないでください。

認証がないため同一人物が複数回参加することは防いでいません。公開ページに人が集まることは保証されません。
